Bear Catering — Official Website

Η επίσημη ιστοσελίδα της επιχείρησης Bear Catering (Παλαιά Πόλη, Ξάνθη — Ετος Ίδρυσης 1994).

Πρόκειται για μια σύγχρονη, πολυτελή και πλήρως αποκρινόμενη (responsive) μονοσέλιδη εφαρμογή (Single Page Application) σχεδιασμένη για την παρουσίαση υπηρεσιών catering και την άμεση εξυπηρέτηση αιτημάτων κράτησης.

Βασικά Χαρακτηριστικά:

🎨 Custom Branding & Theme: Χρωματική παλέτα εμπνευσμένη από το λογότυπο της επιχείρησης (Slate Blue, Sand Gold & Dark Espresso) με typography Playfair Display & Inter.

🌐 Διγλωσσική Υποστήριξη: Πλήρης μεταγωγή γλώσσας (Ελληνικά / Αγγλικά) μέσω JavaScript dictionary.

📅 Διαδραστική Φόρμα WhatsApp: Φόρμα εκδήλωσης ενδιαφέροντος με δυναμικό έλεγχο ημερομηνίας (αποκλεισμός παρελθοντικών ημερομηνιών).

🖼️ Interactive Gallery: Παρουσίαση events (Γάμοι, Βαπτίσεις, Πάρτι, Εταιρικά) με εφέ hover overlay.

📍 Google Maps & Local SEO: Ενσωματωμένο υποσέλιδο με τοποθεσία στην Παλαιά Πόλη της Ξάνθης, στοιχεία επικοινωνίας και βελτιστοποιημένα Open Graph / Meta tags.

📱 Mobile First UX: Floating buttons για άμεση τηλεφωνική κλήση και επιστροφή στην κορυφή.

Τεχνολογίες: HTML5, CSS3, Modern JavaScript (ES6+), GitHub Pages.
